## [0.0.5]

CLI `0.0.5` and TUI `2026.10.5` share this release.

### Features

- Inspect and update Bun and Yarn project dependencies through their native package managers.
- Add guarded Cargo global and standalone-project updates, with stale-state checks and post-update verification.
- Select independent dotfiles and package config files through `CONFICIUS_DOTFILES_CONFIG` and `CONFICIUS_PACKAGES_CONFIG` in both CLI and TUI.

### Fixes

- Resolve Cargo lint failures involving unchecked return values and error strings.
- Restore command heading appearance on the website.

### Documentation

- Document config environment variables, file-path examples, precedence, and error behavior in the README and website.

## [0.0.4]

### Features

- Inspect and upgrade direct Go project dependencies and declared tools while preserving native manifest ownership.
- Classify Go vulnerability findings by application, test, tool, and graph-only usage; add opt-in indirect scans and TUI scan cancellation.
- Add confirmed cross-user global manager execution through a controlling terminal on macOS and Linux.
- Add batch-scoped TUI confirmation for uncommitted project changes and clearer detail-view styling.

### Fixes

- Deduplicate mise Go shims and direct binaries that resolve to the same compiler.
- Show actionable upgrade errors and explicit vulnerability scan scope and progress.

### Documentation

- Expand configuration, privilege, vulnerability-scope, and Go update guidance.
- Add collapsible website navigation, active-section tracking, and clearer command headings.

## [0.0.3]

### Features

- Separate package configuration from dotfile links, with XDG and OS-native layouts.
- Simplify profiles to project groups and enabled managers; native manifests own dependency versions.
- Add APT inventory and cached upgrade inspection, plus confirmed Linux TUI cache refresh.
- Add TUI profile switching, configuration reload on refresh, compact project rows, and clearer shortcut styling.
- Refresh Homebrew metadata before checking available updates.

### Fixes

- Allow TUI startup without dotfile configuration and show optional setup guidance.
- Enforce project update safeguards and reject ambiguous duplicate-manager update plans in TUI.

### Documentation

- Expand website and configuration reference with self-managed dotfiles examples and syntax highlighting.
