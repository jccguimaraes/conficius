Start here

Your terminal. Your choice.

Download a CLI or TUI archive from GitHub releases. Both currently ship as prereleases; the TUI runs without the CLI.

Download releases ↗

Install a release

  1. Choose conficius_VERSION_OS_ARCH.tar.gz for the CLI, or conficius-tui_VERSION_OS_ARCH.tar.gz for the TUI.
  2. Use darwin for macOS or linux, then arm64 or amd64 for your CPU.
  3. Verify your download against the release’s checksums.txt, extract it, and put the binary on your PATH.

Package operations need the corresponding package manager installed. Online checks need network access.

Prefer to build from source?

Use Go 1.26.8 or newer. Run these commands from the repository root:

git clone https://github.com/jccguimaraes/conficius.git
cd conficius
go build -o ./bin/conficius ./cmd/cli
go build -o ./bin/conficius-tui ./cmd/tui

CLI

Inspect first.
Apply when ready.

Start with conficius init to create a configuration. Dotfile linking and package updates preview changes by default; --apply makes them real.

Use --config FILE for an explicit configuration. Otherwise, Conficius searches the current directory and its parents, then $XDG_CONFIG_HOME/conficius/conficius.toml.

Inspection commands support schema-versioned JSON with --json.

conficius / quick start
conficius init
conficius dotfiles audit --xdg
conficius dotfiles link
conficius packages pms
conficius packages outdated
conficius packages vulnerabilities --pm npm --project ./my-app
conficius packages update

Vulnerability findings do not change exit status; inventory or query failures do. Missing package mappings are not evidence that a package is clean.

Configure dotfile links with TOML

Schema version 2. Sources are relative to the config file; target environment variables expand when the config loads. Set ZDOTDIR before using this example.

version = 2

[profiles.default]
mode = "denylist"
manager_order = ["mise", "brew", "npm"]

[[tools.zsh.links]]
source = "zsh/.zshrc"
target = "$ZDOTDIR/.zshrc"
platforms = ["darwin", "linux"]

After reviewing conficius dotfiles link, run conficius dotfiles link --apply to create the links.

TUI

Stay in the terminal.

Run conficius-tui for keyboard-driven package views, dotfile audits, and linking. Inspect outdated versions, configured version drift, and vulnerability findings.

Marked upgrades get a command preview. Confirmed upgrades run in the terminal, then return to the TUI.

Use conficius-tui -config FILE to select a configuration explicitly.
